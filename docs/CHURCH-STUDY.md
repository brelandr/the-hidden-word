# Church study notes & weekly plans

## Publish shared study notes
1. In WP Admin go to **Bible Lessons → Shared study notes**.
2. Choose book, chapter, and optional verse.
3. Add a title and body. Use type **Intro** to override chapter context chips.
4. Optionally set a **Series** name and **Publish on** date for Sunday teaching.
5. Check **Published** so signed-in readers see **Church notes** in the Bible reader.

## Pin a weekly reading plan
1. Create or edit a **Reading Plan** with day readings and discussion prompts.
2. Share the plan URL with your group.
3. Ask members to enable **Share with leader** when submitting reflections so answers appear in the leader inbox (`GET /hwbl/v1/plans/{id}/journal/shared`).

## Moderation
- Uncheck Published or delete a note to unpublish.
- Draft notes stay invisible to readers.
